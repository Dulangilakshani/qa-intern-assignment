# QA Intern Assignment - Part 2: UI Automation

**Author:** Dulangi Thennakoon  
**Website Tested:** [https://safora.se/en/](https://safora.se/en/)  
**Framework:** Selenium WebDriver (Python)

## What This Script Does

This automation script:
1. Opens the Safora website
2. Navigates to the **Contact Us** page
3. Fills out the contact form with test data
4. Submits the form
5. Verifies success message or validation errors
6. Tests form validation by submitting empty fields

## Prerequisites

- Python 3.8+ installed
- Google Chrome browser installed
- ChromeDriver matching your Chrome version

## Installation

```bash
# 1. Install dependencies
pip install -r requirements.txt

# 2. Download ChromeDriver from:
#    https://chromedriver.chromium.org/
#    Place it in your PATH or same folder
```

## How to Run

```bash
python contact_form_automation.py
```
